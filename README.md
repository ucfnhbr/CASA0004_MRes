# Daily Mobility and Socioeconomic Isolation in Sao Paulo

This repository contains selected data and Python notebooks used for an MRes dissertation at the Centre for Advanced Spatial Analysis, University College London.

The research examines how daily mobility relates to socioeconomic isolation across space and time in the Sao Paulo Metropolitan Region. The analysis uses the 2023 Sao Paulo Origin-Destination Survey and considers residential patterns, daily mobility, activity contexts and differences between socioeconomic groups.

## Repository contents

- `2023_OD/`: selected survey data and spatial boundary files.
- `notebook_V1/`: notebooks used for data exploration, analysis and visualisation.

The notebooks correspond broadly to the methodology and research questions presented in the dissertation. Some notebooks may depend on intermediate files produced during the analysis.

## Software

The analysis was conducted in Python using common data analysis, spatial analysis and visualisation libraries. The main dependencies are listed in `requirements.txt`.

```bash
pip install -r requirements.txt
```

## Data source

The main data source is the 2023 Sao Paulo Origin-Destination Survey published by Metro de Sao Paulo:

<https://www.metro.sp.gov.br/pesquisa-od/>

Users should consult the original provider for current documentation and terms of use.
